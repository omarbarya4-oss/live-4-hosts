# موقع بث مباشر: 4 مقدمين + مشاهدون

4 مقدمين يبثون صوتًا وفيديو في نفس الوقت، والمشاهدون يختارون أي مقدم يشاهدونه ويسمعونه، ويتنقلون بينهم بنقرة واحدة.

## التشغيل

1. أنشئ مشروعًا مجانيًا في https://cloud.livekit.io ثم انسخ من الإعدادات: **URL** و **API Key** و **API Secret**.
2. انسخ `.env.example` إلى `.env` واملأ القيم، وغيّر `HOST_KEYS` إلى 4 مفاتيح سرية خاصة بك.
3. ثبّت الحزم وشغّل الموقع (يحتاج Node.js 18 أو أحدث):

```bash
npm install
npm start
```

4. افتح الصفحات:
   - المشاهدون: `http://localhost:3000/`
   - المقدمون: `http://localhost:3000/host.html` (يختار كل مقدم رقمه ويدخل مفتاحه السري)

## كيف يعمل

- `server.js` يصدر رموز الدخول. رمز المقدم يسمح بالنشر ولا يُصدر إلا بالمفتاح السري، ورمز المشاهد للاستماع فقط.
- المشاهد يدخل بدون اشتراك تلقائي، ثم يشترك في مسارات المقدم المختار فقط. عند التبديل يلغي اشتراكه السابق ويشترك في الجديد، فلا يستهلك إنترنت المقدمين الثلاثة الآخرين.
- بطاقات المقدمين تعرض حالة الاتصال ومن يتحدث الآن.

## ملاحظات

- لو دخل مقدم برقم مستخدم بالفعل، يخرج الأول من الغرفة.
- للنشر على الإنترنت يلزم HTTPS (الكاميرا والميكروفون لا يعملان على HTTP إلا في localhost). منصات مثل Render أو Railway أو Fly.io تعطيك HTTPS تلقائيًا.
- الخطة المجانية في LiveKit Cloud لها حد شهري للاستهلاك، فراجع حدودها قبل الإطلاق للجمهور.
